# Copy to tools/denylist.txt (which is gitignored) and add one entry per line.
#
# These are the literal strings that must never appear anywhere in this public
# repository. The recipes here are real and published on purpose; the people
# around them did not choose that. So this list is about people, not numbers:
#
#   - The first names and surnames of everyone in the household.
#   - The names of friends and relatives a recipe is named after or credited to.
#     "Grandma Edith's pie" names a real person in a public repository.
#   - Email addresses and phone numbers, if any ever get written down.
#   - Street names and the town you live in.
#
# Entries are matched case-insensitively, anywhere in a line, and must be at
# least four characters. A very common word will match constantly; prefer a
# surname over a first name like "Ann" if the short one is noisy.
#
# After editing, run:  make denylist
# That regenerates tools/denylist.hashes, which IS committed and is useless
# without tools/denylist.salt. Put the salt in the RECIPES_DENYLIST_SALT
# repository secret so CI runs this tier too.
